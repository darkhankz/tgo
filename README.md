# TGO TRACK — Подготовка к критическому мышлению КТ

Интерактивный 30-дневный план подготовки к магистратуре Казахстана (17 октября — 15 ноября 2026). Основной маршрут: дроби → проценты → уравнения → неравенства → геометрия → пробники.

## Сайт

Откройте `index.html` или включите GitHub Pages: **Settings → Pages → Deploy from a branch → main / (root)**. После публикации: https://darkhankz.github.io/tgo/

Сохранение прогресса работает в браузере (localStorage), без аккаунта и синхронизации между устройствами. При очистке данных браузера прогресс может исчезнуть — пользуйтесь экспортом JSON.
