# TGO TRACK — Критическое мышление (КТ 2026)

Интерактивный сайт для подготовки к критическому мышлению магистратуры Казахстана за 30 дней: дроби, проценты, уравнения, геометрия, диаграммы и повторение.

## Открыть сайт

После включения GitHub Pages в **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)** адрес будет: https://darkhankz.github.io/tgo/

Файл сайта: [index.html](index.html). Доступен без сборки и зависимостей.

## Тренажёр дробей

[Открыть тренажёр](fractions.html) — генерация случайных дробей (числитель и знаменатель до 99), выбор правильных/неправильных дробей и операций сложения, вычитания, умножения и деления. Проверка ответа, подробное решение, счётчик ошибок и верных попыток. Статистика сохраняется локально.

## Возможности

- 30 уроков, разбитых на пять этапов;
- мини-задания с кнопкой показа ответа;
- отметки выполненных уроков и личные заметки;
- хранение прогресса в браузере и экспорт/импорт JSON.

**Важно:** прогресс сохраняется локально для данного браузера и устройства, а не в GitHub.

## Основа плана

План составлен по предоставленным пользователем официальной спецификации ТГО и образцу заданий НЦТ: 15 задач критического мышления, включая сравнение величин (3), математические задачи (8), анализ диаграмм и информации (4).

Официальные PDF доступны в исходном ZIP-архиве, созданном в ChatGPT, но в этот репозиторий пока не загружены. Сайт содержит ссылку на [НЦТ](https://testcenter.kz/).

Цель 11–12 из 15 — ориентир, не гарантия.
